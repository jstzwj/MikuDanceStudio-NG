# v0.0.1 qualification record

Status: **released as a pre-release after all five tagged targets passed**.
[Download v0.0.1](https://github.com/jstzwj/MikuDanceStudio-NG/releases/tag/v0.0.1).

The [coordinated release run 42047576689](https://github.com/jstzwj/MikuDanceStudio-NG/actions/runs/42047576689)
passed for Windows x64, Windows ARM64, macOS Apple Silicon, Linux x64 and
Android. All packages identify source commit
`11c474111e6ea01be2f735c15646ce9620e45d0c`, tag `v0.0.1`, unmodified sources
and non-development builds. The publisher checked all five archives/APK before
publication. The public Release was then checked for its five package assets,
five individual checksums, `SHA256SUMS` and `release-manifest.json`; identities,
file sizes and reported SHA-256 values agree.

The tagged Android APK's certificate fingerprint matches the persistent release
identity documented in the release guide. Its actual installed native viewport
passes background/resume with three subsequent submissions. The macOS job also
passes a native Metal package without MoltenVK.

## Evidence boundaries

Earlier Android runs exposed fixture storage, device-selection and surface
bootstrapping errors; those failed runs do not qualify an APK. The linked final
candidate passes after those fixes. Diagnostic-only reruns record the original
APK commit and cannot supply Release artifacts.

The initial Android profile is a landscape tablet on Android 13+ with Vulkan
1.3. Emulator execution and native ARM64 compilation do not establish physical
ARM GPU coverage. The P4 revised font/Unicode/visual policies remain in force;
physical mixed-DPI monitor qualification is deferred. P5/MME and complete
Ray-MMD execution remain incomplete and are not claimed by v0.0.1.
