## 媒体与 MME 覆盖

| 目标 | 实测设备和后端 | 验收范围 |
| --- | --- | --- |
| Windows x64 | DX11 WARP；NVIDIA TITAN Xp，驱动 `32.0.15.7688`，分别跑 DX11／DX12／Vulkan | 同一个便携包通过搬迁、配置迁移、背景视频、长 WAV、离屏 PNG／MP4、导出取消及失败重试、材质与两级后处理 MME |
| Windows ARM64 | 原生 ARM64 托管环境，DX11 WARP | 同上，另通过五项原生格式、流式 WAV、Qt 音频、背景视频及导出测试。托管机没有原生音频输出端点 |
| Linux x64 | x64 托管环境，Vulkan llvmpipe（LLVM 15.0.7） | 便携包媒体与 MME 验收通过，工作流另通过隔离显示中的呈现与 PulseAudio 静音时钟测试 |
| macOS Apple Silicon | Apple Paravirtual device，Metal | 便携包媒体与 MME、CoreAudio 静音时钟、原生 Metal 呈现及源码行符号通过 |
| Android | API 35 x86_64 隔离模拟器，Vulkan SwiftShader Device (Subzero) | 安装 APK、PMM 导入、WAV 静音播放、背景视频定位、时间轴触摸拖动及后台恢复。APK 内 ARM64 和 x86_64 编解码库的二进制架构均通过检查 |

通过验收的桌面包使用 691,200,044 字节的一小时 WAV。独立解码两种 MP4 得到相同的背景
帧号 `0,0,1,2,3,4`，PCM 音轨共 9,600 个采样帧，左右声道脉冲精确落在第 960–1439
帧。打包应用的六张 PNG 与同一包内命令行入口重复导出逐字节一致。

Android 验收范围为模拟器和两种 ABI 的打包检查。移动端视频导出、运行时 FX、真实 ARM
GPU 和 Windows ARM64 音频设备仍无本轮实机资格。桌面 MME 范围为发行包内的公开测试效果。
完整 Ray／FX9 资格单独由 C3 跟踪。

诊断应记录包 SHA-256、完整源码提交、目标架构和实际渲染设备。`symbols.json` 记录
打包可执行文件和符号文件的哈希，ELF 记录 Build ID，macOS 记录 Mach-O UUID。
各平台的 `editor-media-*` 产物与工作流日志保留对应验收证据，Android 另含
`logcat.txt`。任一目标缺失时，发行门禁不会生成完整五目标候选清单。

macOS 首轮 dSYM 的 UUID 与包匹配，但 Qt 部署时已移除链接调试映射，符号中缺少源码行。
门禁已改为从构建目录的链接产物生成 dSYM，并同时验证源码行表和部署产物 UUID。
最终候选清单使用补验产物的哈希、媒体证据与 dSYM。
补验 dSYM 包含 3,632,462 字节的 DWARF 源码行表和 11,153,571 字节的调试信息。
