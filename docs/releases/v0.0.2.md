# MikuDanceStudio-NG v0.0.2 — Android usability fixes

This preview fixes Android input and presentation and introduces a compact
phone layout. Desktop platforms retain the original-style editor layout.

## Android changes

- Correct finger coordinates for Qt 6.8.3's embedded native windows, including
  File / Preferences, menus, dialogs and buttons. Respect status/navigation bars,
  display cutouts and keyboard resizing without fixed pixel offsets.
- Keep Qt menus and dialogs visible alongside the Vulkan viewport, including
  when accessibility queries overlap native Surface creation. Preference and
  file windows fit the available phone display.
- Present the shared final color image in the displayed orientation. Handle
  both landscape rotations, background recovery and Surface replacement.
  Avoid rebuilding the swapchain every frame for Android's unchanged rotation
  hint, and resume rendering after file-dialog / keyboard resizing without
  blocking the Qt and Android event loops. Defer acquisition while the native
  compositor is busy, without rebuilding or losing model resources.
- Use collapsible Timeline and Controls drawers on phones. Existing editor
  widgets and document state are shared with the tablet layout; panels and
  readouts scroll instead of extending beyond the display.
- Support one-finger camera orbit and two-finger pan/pinch in the viewport.
  Bone selection and axis tools retain their existing editing paths.
- Keep the containing editor accessible when the native viewport has focus,
  and wait for native Surface dimensions before drawing a resized frame.
- Relocate legacy PMM `UserFile` resource paths when folder import gives the
  workspace a new name, preserving model/accessory/media subdirectories.
- Qualify real Android touches, generated PMX/PMM imports, loaded-scene language
  changes and composition/Unicode commits through Android's InputConnection.
  The test keyboard and read-only accessibility observer never ship in the app.

## Downloads

Windows x64 and ARM64 ZIPs, macOS Apple Silicon and Linux x64 tar.gz archives
are portable: extract the entire directory before running. Android uses the
universal ARM64/x86_64 APK, Android 13+ and Vulkan 1.3. It uses the same signing
identity as v0.0.1, allowing an update without discarding application data.

Import an entire Android workspace folder to retain model, texture and motion
paths. Private third-party models used in local checks are not included.

## Scope

This remains an early preview. Full Ray-MMD and arbitrary FX9/MME execution are
not supported; Android has no runtime HLSL compiler. Emulator qualification
does not establish physical ARM GPU compatibility, touch ergonomics or device
performance. Windows archives are unsigned; the macOS app is ad-hoc signed.
Physical mixed-DPI desktop qualification remains deferred.

All five packages must pass the unified Release workflow before publication.
`SHA256SUMS` and `release-manifest.json` identify their hashes and exact source.
