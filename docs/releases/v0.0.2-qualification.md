# v0.0.2 qualification and publication

Published on 2026-11-06 as a preview:
[download v0.0.2](https://github.com/jstzwj/MikuDanceStudio-NG/releases/tag/v0.0.2).
All packages identify source commit `00dac1a48288831123840e92c4e1b91d0f63661c`.

## Qualification

The [unified Release run](https://github.com/jstzwj/MikuDanceStudio-NG/actions/runs/42131980580)
passed Windows x64, Windows ARM64, macOS Apple Silicon, Linux x64 and Android
qualification before publication. Desktop packages passed their editor, render,
media and relocated-package gates. Desktop distributions remain portable archives.

The same signed Android universal APK built in that run passed:

- Deployed fonts, icon, all 15 languages, standard dialog translations and
  offscreen Vulkan rendering.
- Native Surface creation, suspend/resume and device recovery.
- Screenshot qualification of cold start, both landscape rotations, HOME/resume
  and Surface replacement. Incorrect 90/180/270-degree orientations are rejected.
- Actual Android taps on tablet menus, Preferences, Cancel and Go.
- Compact phone drawers/scrolling, camera and timeline touch drags.
- PMM import with relocated historical Windows paths, PMX append, and switching
  English / Simplified Chinese / Japanese with a loaded scene.
- Native InputConnection composition, Japanese and Chinese commits, combining
  accents and Emoji; cancelled Save As and subsequent viewport submissions.

The emulator-only keyboard and read-only accessibility helper are excluded from
the product APK. Fresh emulator service policy and slow accessibility traversal
are handled in the test harness; complete-tree, visible-control and actual-edit
checks remain mandatory. Stalled or indefinitely progressing queries still fail.

Independent local headless Lavapipe tests passed the same workflows, including
an original PMM scene with three models/stage followed by a real PMX append
(four models total). Private assets and their screenshots remain local and are
excluded from source, CI uploads and release assets. Only the owned emulator
received local input; its settings were restored and it was shut down.

## Scope

This is a preview, not full MME/Ray-MMD qualification. Android currently uses
landscape orientation and requires Android 13+ and Vulkan 1.3. Emulator results
do not establish physical ARM GPU compatibility, touch ergonomics or device
performance. Android has no runtime HLSL compiler. Windows archives are unsigned;
the macOS app is ad-hoc signed. Physical mixed-DPI desktop qualification remains
deferred. See [release notes](v0.0.2.md) and [Android UI contracts](../ANDROID_UI.md).
