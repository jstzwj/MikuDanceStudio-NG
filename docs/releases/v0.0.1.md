# MikuDanceStudio-NG v0.0.1 — the first portable preview

Our first preview brings the familiar MMD workflow to a shared Qt editor and
modern rendering backends. This is an early development release, not a claim of
complete MMD/MME or Ray-MMD compatibility.

## Downloads

| Package | System | Renderer |
| --- | --- | --- |
| Windows x64 portable ZIP | Windows 10/11 x64 | DX11 default; DX12 and Vulkan available |
| Windows ARM64 portable ZIP | Windows 11 ARM64 | Native ARM64 DX11; DX12 and Vulkan available |
| macOS ARM64 portable tar.gz | macOS 13+, Apple Silicon | Native Metal default; Vulkan/MoltenVK available |
| Linux x64 portable tar.gz | Ubuntu 22.04 or compatible x64 | Vulkan 1.3 |
| Android universal APK | Android 13+, ARM64 or x86_64, Vulkan 1.3 device | Vulkan; experimental tablet/landscape UI |

Desktop packages are portable: extract the entire folder and run the editor.
There are no desktop installers. Qt, translations, fonts and compiler/runtime
dependencies ship with the package. Linux still requires compatible system
libraries and a Vulkan loader/driver. Android uses a signed APK, as required by
the OS, rather than a desktop-style portable archive.

## In this preview

- Shared PMM/model/motion editing, CPU animation and physics, save/reopen,
  timeline, bone selection and history.
- Native Qt editor with 15 languages; choose a language in File → Preferences.
- Shared RHI model rendering, self-shadowing and image-sequence export.
- Desktop packages include their matching runtime HLSL/SPIR-V compiler.
- Android uses precompiled built-in shaders. Import an entire workspace folder
  before opening a project to preserve model/motion/texture paths.

## Scope and known limits

- P5's portable FX9/MME execution migration is in progress. Full Ray-MMD and
  arbitrary `.fx` execution are not supported by this release. Android does not
  include a runtime HLSL compiler.
- Android's first UI targets landscape tablets; it is not a finished phone UI.
- Hosted software GPUs/emulators validate the published scope; they do not
  establish performance or compatibility for every physical GPU/device.
- Original Windows controls remain the behavioral reference. Open-font glyph
  differences and complete Unicode display follow the accepted P4 policy.
  Physical mixed-DPI cross-monitor qualification remains deferred.
- Windows packages are unsigned; the macOS app is ad-hoc signed. No external
  models, motions, effects, or commercial assets are included.

Each release supplies `SHA256SUMS` and `release-manifest.json`. The manifest
records the exact source commit and platform identities; desktop archives also
contain `build-info.json` and `VERSION`. Qualification details and limitations
are maintained in [the release guide](https://github.com/jstzwj/MikuDanceStudio-NG/blob/main/docs/RELEASES.md).
