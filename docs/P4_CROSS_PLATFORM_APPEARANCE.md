# 跨平台外观复验范围

本轮复看运行 `41843478422` 保存的 Windows／Linux／macOS 三语言界面图像，
每平台两种窗口尺寸，共十八张。报告来自真实生产编辑器的离屏组合，
`editor-chrome/report.json` 保留窗口与视口尺寸，图像没有重采样后参与验收。

为检查字体，又从三平台 1920 像素图像直接裁出菜单、顶栏及底部控件，按语言并排。
本地检查图为 `out/build/p4-font-appearance-review.png`；每块保持原始像素，
只添加平台／语言／运行号标签。它是辅助检查图，不替代原始整图。

这批截图里，侧栏和底部区域、背景色、控件排列、三语言标签以及视口方向一致。
没有发现缺字或整块控件错位；已能看出平台字体的字重、宽度和栅格差异。
macOS 当轮另有菜单字体继承门禁失败，后续代码修复已在 Windows／Linux 通过，
但两轮 macOS 任务因托管容量未开始执行，因此不能用旧图给修复后的 macOS 授予资格。

**完整非 Windows 外观仍未验收。** 当前离屏整图不能证明实际窗口装饰、焦点、
悬停、弹出菜单、滚动、输入法候选或真实 DPI 的表现；它也不覆盖全部数值对话框。
所附 Noto 字体确保 CJK 字形来源稳定，不能据此声称与 Windows 的原版字体逐像素一致。
用户针对完整渲染场景接受的视觉比较，不自动豁免 UI／输入的独立验收要求。

后续实际验收需要单独保留 OS、QPA、DPR、字体解析结果、相应原版／Qt 控件状态
及原始截图。发现差异时先定位控件几何、字体度量、绘制或交互原因，不修改截图
来隐藏差异。历史图像与报告的哈希见 [UI 运行记录](evidence/p4-ui-41843478422.json)；
总体结论见 [当前验收表](P4_ACCEPTANCE_STATUS.md)。
