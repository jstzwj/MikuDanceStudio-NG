# P4 显示态与完整 Unicode 补验

本专项承接 [P4 当前验收表](P4_ACCEPTANCE_STATUS.md)，不重复已经通过的原生输入法、
音频和整帧渲染专项。实际显示、焦点、系统鼠标及键盘输入仅在隔离 runner 上执行。
本地检查只使用离屏渲染、内存 DC 或从未显示的自有窗口；保护拒绝分支先于 QApplication。

## 验收范围

- Windows：三语言、六个方向共 18 次实际客户区外拖选。等待指针静止，检查真实捕获、
  选区、首个可见行、水平偏移及完整客户区 RGB；不能只比较最终选择或直接发送 Qt 事件。
- Windows：五种公开 Unicode 文本、选中／未选中、三种 UI 语言共 30 个实际焦点状态，
  包括真实 Ctrl+A、删除、撤销重做及不拆分组合字符的字词导航。
- Linux／macOS：每种语言 19 类对话框，共 57 个显示态配置；27 个生产编辑器菜单，
  45 个输入焦点、51 个实际指针悬停、12 个下拉弹出、9 个列表滚动及 3 个多行滚动。
  物理对话框使用公开生成 PMD 绑定真实 ModelPhysicsDialog，不以通用模板代替。

`QWidget::grab` 只捕获窗口客户内容，不包括操作系统窗口装饰。报告分别保存 QPA、
实际 DPR、逻辑／物理尺寸、字体解析和子控件几何，不能扩大为全部字体／窗口装饰／DPI 资格。

## Unicode 政策

用户已确认：原版能正确显示的传统文本保持严格原版对照；原版损坏或不能完整显示的
组合字符、Emoji、复杂排版和其他 Unicode，NG 保留文字完整、可读、可编辑及输入法正常。
原版英文备注框含 ES_OEMCONVERT，甚至在 SetWindowTextW 后将部分文字改成下划线；
不复制这种数据损坏。原始图像差异仍保存，不能把诊断差异统称为精确匹配。

隐藏专项有 360 个 Unicode 状态，其中 96 个原版能正确显示的传统 CJK 状态严格逐像素比较；
全部 360 个状态检查完整文字。实际焦点专项另有 8 个传统 CJK 客户区严格比较。

## 定位与修复

1. 原版 EDIT 在实际鼠标移动时滚动；指针停在客户区外时不持续滚到文档边缘。
   Qt 默认定时自动滚动导致选区、行号和水平偏移错误。生产编辑器保留实际 Qt 捕获，
   对受支持的传统 ASCII 拖选按原版边缘命中、三分之一客户宽的整列滚动和释放规则处理。
   复杂 Unicode 仍使用 Qt 的完整命中与排版。
2. 18 个实际拖选的剩余截图差异全部是一列 12／14 像素的光标。最初认为是采样相位，
   但平衡 HideCaret／ShowCaret 无效；41972392409 完整周期观察进一步证明：原版在客户区
   外释放拖选后始终保持一幅光标隐藏画面，NG 错误地继续闪烁。这是行为差异，不能仅修
   捕获时机。生产控件现保留外部释放后的隐藏状态，下一次按键、焦点或鼠标按下恢复。
   专项要求完整周期的图像集合及数量完全相同，不假设原版必有两个相位；额外画面也失败。
   不更改原生光标隐藏计数、焦点、位置或系统设置，不删光标、不屏蔽像素。
3. 普通中日文沿用原生 GDI 字形；MS UI Gothic 与 Noto 回退混合曾把 12 像素行高
   扩为 17，导致两幅选中中文截图出现 101×5 的额外选区。Windows 优先使用已安装的
   度量兼容 SimSun 回退；实际 QTextLine 排除 EDIT 不采用的 external leading，统一选区、
   光标、命中、滚动与 IME 坐标。组合排版和预编辑继续保持完整 Qt 行距。438 个既有原版
   字符坐标之外，增加 12 个 CJK 回退行／光标断言；不通过裁剪绘制掩盖布局错误。
   完整本地回归还发现直接替换已附加布局会使 QPlainTextEdit 保留悬空指针；现改为
   通过 setDocument 安装新文档，保留原字体与 viewport 绘制设备，覆盖正常销毁与缩放。
4. macOS 的系统白色背景与原版不一致。非 Windows 使用固定原版浅灰对话框配色，
   保留独立平台字体和实际输入实现；记录颜色并通过字体／显示态门禁复验。

## 开放字体范围与长标签

用户进一步确认：非 Windows 允许开放字体字形差异，控件几何、换行、文字完整及操作仍
保持严格；Windows 原版控件对照不放宽。复杂 Unicode 的完整显示政策也保持独立。

实际截图中的英文附件顺序说明缺少第二行，日文物理关键帧说明右侧裁切。根因为 QLabel
没有实现原始 SS_LEFT 的换行契约，Noto 全宽假名又宽于 MS UI Gothic 的比例字形。
DialogStaticLabel 保留原模板几何、完整文本和字体高度，支持原版换行；仅当开放字体
会超出矩形时调整字形宽度。恢复宽度、动态物理标签及父窗口语言字体继承均有回归。
Windows 使用原始字符集、DrawText 和禁用文字浮雕掩码，536 个隐藏原生标签状态精确匹配；
三语言 804 个离屏标签状态完整。实际 X11／Cocoa 显示态的字形、换行及裁切另行复验，
不以离屏通过代替真实显示。相关截图和范围见 [跨平台外观](P4_CROSS_PLATFORM_APPEARANCE.md)。

41975627370 的标签自身布局检查全部通过，但实际截图复看发现英文附件说明的父窗口
裁切：原标签超出父窗口，开放字体新增到首行的单词被父客户区裁掉。修复进一步采用
所有祖先客户区的实际交集作为文本宽度；原控件矩形不变。显示态门禁同时检查完整
内容矩形被所有祖先包含，避免再次仅凭自身 QTextLayout 授予完整文字资格。

真实混合 DPI 跨屏尚未执行。所需独立环境和程序见 [真实 DPI 验收](P4_PHYSICAL_DPI.md)。
所有显示态截图目前实际 DPR=1，不代表 Retina、跨屏或系统窗口装饰已在本专项获得资格。
