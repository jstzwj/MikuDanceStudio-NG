# 多行 EDIT 的隐藏客户区绘制对照

生产修复提交 `105695e`，Qt 6.8.3，Windows QPA。新增 `qt_multiline_paint` 使用现有
字节核验资源的 `666/665` 模型备注对话框；原生对照来自实际 EDIT 的
`WM_PRINTCLIENT`，Qt 图像来自从未显示的真实生产控件。

**432/432 个客户区状态精确匹配 RGB**：三种 UI 语言 × 六类 ASCII 文本 ×
启用／禁用／只读／禁用只读 × 初始／垂直滚动／水平滚动 × 无选区／保留选区。
短文本没有可滚动范围时仍验证状态保持，超宽行和多行文档验证实际滚动后的输出。
英文使用英文原版资源，中／日使用日文原版资源。每种语言保留一对成功图像，失败时
保存全部差异图像；比较不裁掉客户区边缘、不屏蔽像素、不放宽阈值。

修复覆盖：

- 只读客户区使用系统对话框底色；禁用文字使用原生系统灰色。
- GDI 字形渲染使用 Qt 实际字体和文字布局位置，Tab、空行和行高不重新推测。
- 一像素文档边距保留首字形伸入边距的绘制空间；字符及行原点保持原版冻结值。
- Qt 只在文档首块应用上边距，原生 EDIT 滚动后仍保留格式区上边距，现已补齐。
- 区分未滚动字形伸展与滚动后的格式区裁切，修正上下／左右边界的残留像素。
- 原版资源没有 `ES_NOHIDESEL`，因此失去焦点后不绘制保留的选区。

Qt 继续管理真实文档、选择、撤销、命中、滚动和输入法。Windows 的内存 GDI
适配只绘制未聚焦、没有活动预编辑的简单 ASCII 文本；Unicode、复杂排版及活动
焦点继续使用 Qt。它不创建或嵌入原生编辑控件，也不复制原版 ANSI 备注的数据丢失。

修改后，原有 **50,232 个命中＋475 个直接 Shift 点击、438 个文字／Tab 原点、
864 个多行导航／翻页比较**全部通过。`out/build/p4-multiline-scroll-insets.xml`
记录此前 216 状态版本及三项原有门禁；完整 432 状态版本已通过最新 **41/41**
Qt 回归、ALL_BUILD 和更新后的 `out/dist` 搬迁启动。源文件、报告和发布包哈希见
[本地证据](evidence/p4-multiline-paint-local.json)。

这个专项只验收**隐藏客户区、未聚焦状态**。外部边框、显示态活动选区／闪烁光标、
实际鼠标捕获／拖选／自动滚动、Unicode 字形、非 Windows 原生外观和真实跨屏 DPI
不由此获得资格。当前完整阶段结论见 [P4 验收表](P4_ACCEPTANCE_STATUS.md)。

隐藏观察器后续使用创建前的外层 `WS_EX_NOACTIVATE` 和仅自身 GUI 线程的
`WH_CBT`，拒绝 `HCBT_ACTIVATE/HCBT_SETFOCUS`。创建前标志本身不能拒绝
USER32 的显式激活；该实际失败保留在证据中。资源子控件、字体和尺寸未改动，
强制的前台／焦点断言继续生效。真实显示态专项没有这层适配。

新增 `qt_multiline_active_test` 不注册进普通 CTest；在 QApplication 创建前要求
`GITHUB_ACTIONS=true` 和 `MDS_QT_ISOLATED_DISPLAY=1`。它使用未修改资源、
真实原生焦点及 OS 鼠标捕获比较三语言的 72 个活动绘制状态和 90 个鼠标手势。
所有活动图像及原生／Qt 光标矩形会保留，任何差异都失败。首次定向任务为
[41861823315](https://github.com/jstzwj/MikuDanceStudio-NG/actions/runs/41861823315)，
未实际执行前不能将这些状态记为通过。超出客户区的拖选自动滚动、真实 DPI
及 Unicode 字形仍需另外验收。
