These license texts are unmodified files from Qt Base tag v6.8.3:
https://github.com/qt/qtbase/tree/v6.8.3/LICENSES

The additional `FFmpeg-*` files are unmodified n7.1 source license texts:
https://github.com/FFmpeg/FFmpeg/tree/n7.1

The complete set is retained because the official shared SDK and its plugins
include third-party code under several licenses. Component attribution and
corresponding source locations are listed in docs/THIRD_PARTY_RUNTIME.md.
