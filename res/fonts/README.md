CMake downloads and verifies the collection. Offline builds can provide the same
file through `MDS_EDITOR_FONT_FILE`. No Microsoft or Apple fonts are distributed.
Installed original fonts remain preferred. The fallback guarantees CJK glyph
availability; it does not establish identical font metrics or glyph painting.
